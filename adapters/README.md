# Sextant adapters

Sextant has one agent-agnostic core and thin host adapters. `npx sextant init` can detect common hosts and install the appropriate instruction layer. Use `npx sextant doctor` to inspect the installation.

Current adapters: generic AGENTS.md, Claude Code, Codex, Cursor, OpenCode, Gemini-style hosts, Cline, Roo Code, and GitHub Copilot.
