# Sextant benchmark

The benchmark compares:

A. baseline agent
B. Ponytail
C. Sextant
D. Sextant + Ponytail

Use identical model, repository commit, task text and tool access.

Primary metrics:
- successful task rate
- total tokens and cost
- time
- failed attempts
- reverted work
- regressions
- unnecessary files/LOC
- human intervention
- wrong-path investigations
- falsified hypotheses
- correct no-change decisions

Primary Sextant metric:

> **Decision efficiency = successful engineering outcomes / total work spent**
