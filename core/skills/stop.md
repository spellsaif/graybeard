# Sextant Skill: Stop

Purpose: prevent unjustified code changes.

Valid stop reasons:
- already solved;
- wrong root cause;
- insufficient evidence for the risk level;
- conflicting requirements;
- unsafe requested implementation;
- invariant would be weakened;
- no meaningful code change is required.

A stop is a successful engineering outcome when evidence supports it.

Output state:
STOP, STOP_REASON, EVIDENCE.
